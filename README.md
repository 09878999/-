# 静时 · Still Focus

一款自用的 iPad 学习时长记录 PWA。没有倒计时、没有账号、没有云同步，只记录真实投入的学习时间。

## 功能

- 按科目开始正计时，支持暂停、继续与结束保存
- 页面关闭或切到后台后，按真实时间恢复计时
- 手动补记、编辑和删除学习记录
- 今日、近 7 天、近 30 天学习时长统计
- 科目分布与近 12 周学习热力图
- 学习科目管理
- 本地 JSON 备份导出与恢复
- 可安装到 iPad 主屏幕并离线使用

## 本地开发

```bash
pnpm install
pnpm dev
```

## 验证

```bash
pnpm test
pnpm build
```

## 安装到 iPad

1. 将 `dist/` 部署到任意免费静态托管服务。
2. 在 iPad Safari 中打开站点。
3. 点击分享按钮，选择“添加到主屏幕”。

支持部署到 GitHub Pages、Cloudflare Pages 等静态托管。构建资源使用相对路径，可部署在子路径下。

## 数据说明

所有数据保存在当前浏览器的 IndexedDB 中，不会上传到服务器。清除 Safari 网站数据会删除记录，因此建议定期在“设置 → 数据备份”中导出 JSON 文件。
