一款面向 iPad 的本地优先学习专注计时 PWA，支持科目正计时、沉浸式全屏、目标管理、学习统计、离线使用与 JSON 数据备份，无需账号或云同步。  项目简介：  专注记录钟（静时 · Still Focus）是一款自用的学习时长记录应用，用来记录真实投入的学习时间。应用可以按科目开始正计时，并支持暂停、继续、结束保存，同时还提供全屏沉浸计时、学习目标管理、今日及近 30 天统计、科目分布、学习热力图和数据备份等功能。  项目基于 React、TypeScript 和 Vite 构建，数据保存在本地 IndexedDB，不依赖账号或云服务；作为 PWA，可安装到 iPad 主屏幕并离线使用。
